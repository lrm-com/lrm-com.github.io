本地音乐库

导入本地文件夹，递归扫描 MP3、FLAC、WAV、OGG、M4A、AAC，并按歌曲、艺术家、专辑、文件夹和歌单浏览。

沉浸歌词

支持内嵌歌词、本地 LRC/TLRC/TXT、翻译歌词、歌词偏移、逐词高亮和多种全屏歌词布局。

桌面歌词

独立置顶歌词窗口，支持拖动、锁定、双行、翻译、逐字显示、切换动画和颜色描边配置。

系统体验

支持系统托盘、任务栏媒体控制、顺序/循环/随机播放、主题模式和封面强调色。

关于 Still ​

Still 是一个基于 React、Vite 和 Electron 构建的本地桌面音乐播放器，专注于本地音乐库管理、沉浸式歌词、桌面歌词和轻量顺手的播放体验。

当前版本 ​

1.0.0-beta.2

Still 目前处于 beta 阶段，功能和界面会继续迭代。Windows 用户可以前往 Releases 下载最新安装包。
