开发说明 ​

Still 使用 React、TypeScript、Vite 和 Electron 构建。

环境 ​

建议使用较新的 Node.js 版本，并在项目根目录安装依赖。

bash
npm install

命令 ​

bash
npm run dev
npm run build
npm run preview
npm run dist
npm run pack

命令说明：

  • npm run dev：启动 Vite 开发服务
  • npm run build：构建前端资源
  • npm run preview：预览前端构建产物
  • npm run dist：构建前端并打包 Windows 安装包
  • npm run pack：构建前端并生成未安装包目录

项目结构 ​

text
electron/      Electron 主进程和预加载脚本
src/           React 应用源码
logo/          应用图标和 logo 资源
docs/          截图和项目文档资源
dist/          前端构建输出
release/       Electron 打包输出

Electron 接口 ​

预加载脚本通过 window.electronAPI 暴露受控能力：

  • window：最小化、最大化、恢复、关闭、全屏状态
  • library：读取元数据、导入文件夹、导入路径、解析封面、加载和保存应用状态
  • desktopLyrics：打开、更新、锁定桌面歌词，并接收桌面歌词命令
  • player：同步播放状态，并接收托盘、任务栏或桌面歌词发来的播放命令

打包 ​

Windows 打包由 electron-builder 负责。

应用信息：

  • appId: com.still.player
  • productName: Still
  • 输出目录：release
  • Windows 图标：logo/Still_logo_white/Still_logo_white_rounded.ico
  • 安装包命名：Still_v${version}.${ext}
